## 描述

在模运算里没有除法。`7 / 3 mod 11` 没有意义，取而代之的是「乘 3 的逆元」：
找一个 `x` 使 `3 * x ≡ 1 (mod 11)`，得到 `x = 4`（因为 `12 mod 11 = 1`），
于是 `7 / 3` 就按 `7 * 4 = 28 ≡ 6 (mod 11)` 来算。这个 `x` 就是 3 在模 11 下的**乘法逆元**。

这不是一个抽象练习：RSA 的私钥 `d` 就是 `e` 在模 `φ(n)` 下的逆元（`e·d ≡ 1 mod φ(n)`）；
仿射密码、椭圆曲线签名、Shamir 秘密分享里到处是它。`a` 在模 `m` 下可逆的充要条件是 `gcd(a, m) = 1`；
模数是素数 `p` 且 `a` 不是 `p` 的倍数时，逆元一定存在。

附件给出 `a` 和一个 61 bit 的素数模数 `m`，要求解出 `x`：

```
a = 314159265358979323
m = 2305843009213693951      # 2^61 - 1，素数
a * x ≡ 1 (mod m)
```

`x` 的十进制写法就是 **flag** **花括号**里的内容。

## 原理

**为什么逆元存在。** `a*x ≡ 1 (mod m)` 等价于存在整数 `x, y` 使 `a*x + m*y = 1`。
Bezout 定理说 `a*x + m*y` 能取到的最小正整值就是 `gcd(a, m)`，所以方程有解 ⟺ `gcd(a, m) = 1`。
模数是素数 `p` 时，只要 `a` 不是 `p` 的倍数就满足条件，逆元一定存在且在 `[0, p)` 内唯一。

**扩展欧几里得为什么能算出来。** 它是欧几里得算法的副产物：`gcd(a, m) = gcd(m, a mod m)`，
递归到 `gcd(g, 0)` 时可以直接写出 `g*1 + 0*0 = g`，再逐层回代把 `g` 表示成 `a, m` 的组合。
每一步的系数都是上一步系数的线性组合，所以栈深只有 `O(log m)`，61 bit 的模数十几层就到底了，
这就是为什么它比「从 1 试到 m」快得多（后者 `O(m)`，对 `2^61` 完全不可行）。

**为什么模逆元是密码学的零件。** RSA 的 `d = e^{-1} mod φ(n)` 是逆元；ElGamal/ECDSA 的签名里
`s = k^{-1}(h + r·d) mod n` 也是逆元；仿射密码 `E(x) = ax + b` 要求 `a` 在模 26 下可逆。
这些地方一旦逆元算错或模数选错（不互素），则系统立即崩溃。
